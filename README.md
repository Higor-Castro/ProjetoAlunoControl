# Projeto AlunoControl - Sistema de Cadastro

Este projeto foi desenvolvido com o objetivo de praticar **JavaScript (ES Modules)**, **padrão MVC** e **LocalStorage**, criando um sistema simples, organizado e interativo para cadastro de alunos e coleta de pesquisa de satisfação.

---

## Funcionalidades

* **Cadastro de Alunos**: Registra nome, idade e outros dados relevantes.
* **CRUD Completo dos Alunos**: Criar, listar, editar e excluir alunos usando LocalStorage.
* **CRUD Completo da Pesquisa de Satisfação**: Permite registrar, listar, editar e excluir avaliações.
* **Mensagens de Feedback**: Exibe mensagens dinâmicas para o usuário.
* **Arquitetura MVC**: Separação clara entre Model, View e Controller.
* **Uso de ES Modules**: Organização modular com `import` e `export`.

---

## Tecnologias Utilizadas

* **HTML**: Estrutura do layout e formulários.
* **CSS**: Estilização da interface.
* **JavaScript (ES Modules)**: Lógica, controle e manipulação do LocalStorage.
* **LocalStorage**: Salvamento dos dados localmente.
* **VSCode**: Editor de código utilizado.
